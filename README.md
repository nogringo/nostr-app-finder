# Nostr app finder

Browse and discover Nostr applications with smart search and filtering. The online version is available [here](https://nogringo.github.io/nostr-app-finder/).

## Search features

- keywords
- features
- platforms
- kinds
- tags

## Contributing

This project use Nostr to communicate, fill issues and open PRs. Contributions are welcome, feel free to open PR. You can view the repository online with [gitworkshop](https://gitworkshop.dev/npub1kg4sdvz3l4fr99n2jdz2vdxe2mpacva87hkdetv76ywacsfq5leqquw5te/nostr-app-finder).
